# Burdier Church

## Administrar la radio

Las publicaciones de la sección Radio se administran en `_data/radio.yml`. Cada entrada requiere `url`, `title`, `artist`, `style` y `platform`; actualmente el reproductor admite `youtube` y `audiomack`.

El álbum de Audiomack ocupa una sola entrada. Sus canciones se eligen y reproducen dentro del embed, con espacio para la lista en móvil. Se inicia con Play dentro de Audiomack; los botones externos Anterior y Siguiente cambian entre las entradas de Radio.
